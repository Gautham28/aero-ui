Ultra-lightweight UI library

Class-based, minimal, zero dependencies. ~10KB CSS and JS.

aero UI is an ultra-lightweight HTML + CSS component library with zero dependencies. No framework, build, or dev complexity. Just include the tiny CSS and JS files and you are good to go building decent looking web applications with most commonly needed components.

It utilizes a familiar class-based system (like .aero-btn) inspired by the shadcn aesthetic, keeping your raw HTML elements unpolluted while providing premium styling out of the box.

Light like air

~10KB CSS, 1KB JS, minified + gzipped.

That's it.

Zero dependencies

Fully-standalone with no dependencies on any JS or CSS frameworks or libraries. No Node.js ecosystem garbage or bloat.

Familiar Classes

Components use a predictable namespace (.aero-*). Drop it into any existing project without worrying about global style collisions.

Easy customization

Easily customize the overall theme by overriding a handful of CSS variables. Automatically picks up dark theme based on system preferences.

Why?

This was made after unending frustration with the over-engineered bloat, complexity, and dependency-hell of pretty much every modern Javascript UI library and framework out there.

My goal is a simple, minimal, vanilla, standards-based UI library that I can use in my own projects for the long term without having to worry about build tools breaking. Long term because it's just simple vanilla HTML and CSS. The look and feel are heavily influenced by the beautiful shadcn aesthetic.
