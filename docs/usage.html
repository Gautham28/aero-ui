Installation and Usage

IMPORTANT: aero UI is currently in v1-beta.

CDN

Include the bundled CSS directly in your HTML header:

<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/your-username/aero-ui/src/aero.css">
<script src="https://cdn.jsdelivr.net/gh/your-username/aero-ui/src/js/dialog.js" defer></script>

Download

Download the source files directly to your project:

curl -O https://raw.githubusercontent.com/user/aero-ui/main/src/aero.css

Basic Usage

aero UI uses a class-based system inspired by shadcn for maximum compatibility:

<html>
  <head>
    <link rel="stylesheet" href="aero.css">
  </head>
  <body>
    <h1>Hello World</h1>
    <button class="aero-btn">Click me</button>
  </body>
</html>
