Usage

Getting started with aero UI is incredibly simple. No build tools, no package managers, and absolutely zero dependencies.

1. The Base Setup (Required)

First, copy the src/css and src/js folders into your project. Then, link the base.css file inside your HTML's <head>. This file acts as the engine for the library—it contains all the CSS variables for the light/dark themes, the typography rules, and basic browser resets. 

<!DOCTYPE html>
<html lang="en">
<head>
  <!-- Include the base engine -->
  <link rel="stylesheet" href="path/to/css/base.css">
</head>

2. Import Components A La Carte

aero UI is completely modular. To keep your website's payload as small as an oat flake, only link the specific CSS files for the components you intend to use on that specific page. 

<head>
  <link rel="stylesheet" href="path/to/css/base.css">
  
  <!-- Only import what you need! -->
  <link rel="stylesheet" href="path/to/css/button.css">
  <link rel="stylesheet" href="path/to/css/card.css">
</head>

3. Add Interactivity (Optional)

Most of aero UI is pure CSS. However, a few dynamic components (like the Dialog modal) require a tiny amount of vanilla JavaScript to handle click events. If you are using these components, link the JS file right before your closing </body> tag. 

<body>
  <!-- Your beautiful UI goes here -->

  <!-- Import tiny JS scripts at the end -->
  <script src="path/to/js/dialog.js"></script>
</body>
</html>

4. Customizing the Theme

Want to change the default shadcn-like dark theme to something else? Simply open your `base.css` file and modify the CSS variables in the :root selector. The entire component library will automatically update to match your new colors. 

/* Inside base.css */
:root {
  --primary: #3b82f6; /* Change to a brand blue */
  --radius: 0.5rem;   /* Make corners slightly rounder */
}
