Installation and Usage

Pin a version in CDN URLs (e.g. @1.0.0) for stable installs in production.

npm

Install the package from npm:

npm install @gautham28/aero-ui

Then import in your project (bundler):

import '@gautham28/aero-ui/aero.css';
import '@gautham28/aero-ui/dialog.js';

CDN

Include the CSS and JS directly in your HTML (via jsDelivr):

<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/@gautham28/aero-ui@1.0.0/src/aero.css">
<script src="https://cdn.jsdelivr.net/npm/@gautham28/aero-ui@1.0.0/src/js/dialog.js" defer></script>

Download

Download the bundled CSS from GitHub:

curl -O https://raw.githubusercontent.com/Gautham28/aero-ui/main/src/aero.css

Basic Usage

aero UI uses a class-based system inspired by shadcn for maximum compatibility:

<html>
  <head>
    <link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/@gautham28/aero-ui@1.0.0/src/aero.css">
    <script src="https://cdn.jsdelivr.net/npm/@gautham28/aero-ui@1.0.0/src/js/dialog.js" defer></script>
  </head>
  <body>
    <h1>Hello World</h1>
    <button class="aero-btn">Click me</button>
  </body>
</html>
